# Hospital Management System

## Project Overview

The Hospital Management System is a DBMS project designed to manage
hospital information including patients, doctors, departments,
appointments, medical records, prescriptions, rooms/wards and bills.

## Entities

1. Patient
2. Doctor
3. Department
4. Appointment
5. Medical Record
6. Prescription
7. Room/Ward
8. Bill

## Repository Structure

- dataset/ – 8 CSV files
- sql/ – CREATE TABLE, INSERT and SQL queries
- erd/ – ER diagram
- ppt/ – Review presentations
- docs/ – Project report/documentation
